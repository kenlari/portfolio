Crypto range — seven writeups · kennethlari

From encoding stacks to ECDSA nonce reuse, each break explained and reproduced.

Writeups — all seven

Every flag below was produced by python3 work/solvers.py. That script is the reference implementation; this file is the reasoning, which matters more.

C1 — Encoding is not encryption · flag{enc0ding_is_not_encryption}

hex -> base64 -> rot13

Three "locks", zero keys. The tells:

Layer Tell
hex only 0-9a-f, length even
base64 alphabet A-Za-z0-9+/, length % 4 == 0, trailing =
rot13 output still looks like text but f→s, l→y, so flag{ reads as synt{

Lesson: encoding ≠ encryption. Anyone with base64 -d is inside. If you find this in a real app (e.g. a "secure" token that is just base64), that's an information-disclosure bug, not crypto.

C2 — Single-byte XOR · flag{single_byte_xor_reveals_secrets}

The key is one byte, so there are only 256 possible plaintexts. Never eyeball them — write a scorer.

score(plaintext) = sum(log(P(byte)))
  • English letters get their real frequency (space 18%, e 10%, t 7.5%, …)
  • Punctuation/digits get a flat small weight
  • Non-printable bytes get a large penalty (this is the big separator)

Take the max over 256 keys. Key was 0x42.

Lesson: a 1-byte keyspace is 8 bits. It is brute-forceable by hand.

C3 — Repeating-key XOR · flag{repeating_keys_leak_like_rusted_pipes}

Two-step attack:

  1. Find the key length. For each candidate ks, take consecutive blocks of ks bytes and compute the normalized Hamming distance (bits differing per byte). Correct key length aligns the blocks on the same key bytes, so the distance drops. Real key length was 5.
  2. Split and conquer. Transpose the ciphertext into ks columns. Column i is a plain single-byte XOR (C2). Solve each, concatenate the keys → lem0n.

Lesson: repeating a short key is what kills it. Real stream ciphers use a nonce + a PRF so the keystream never repeats.

C4 — Vigenère · flag{vigenere_falls_to_frequency_analysis}

Vigenère is keylen interleaved Caesar ciphers, so:

  1. Key length via index of coincidence. For candidate lengths, split into columns and average IC = Σ n_i(n_i-1) / n(n-1). English sits near 0.066; wrong lengths sit near uniform-random 0.038. Key length 6.
  2. Shift per column via chi-square. Compare each column's letter distribution to English frequencies; the shift minimizing chi-square is that Caesar key. Shifts spell cipher.

Lesson: polyalphabetic ≠ secure. It resisted frequency analysis for 300 years only because nobody counted.

C5 — Weak hash, weak password · flag{mollycat}

07d6ba4b8935a4d7d6ac6b402610420d is bare MD5 — no salt, no iterations, no memory hardness. It fell in 3 seconds to a wordlist, at line 40,001 of rockyou:

john --format=raw-md5 --wordlist=wordlists/rockyou.txt work/a.md5
john --show --format=raw-md5 work/a.md5     # ?:mollycat

Lesson: this is the single most common real-world finding. Correct fix is Argon2id / bcrypt / scrypt with a per-user salt — and a password that isn't in a leaked corpus.

C6 — RSA with e=3, no padding · flag{rsa_without_padding_is_a_bad_idea}

Textbook RSA computes c = m^e mod n. With e = 3 and no padding, a 39-byte message gives m^3 — which is smaller than n, so the mod n never wraps. The ciphertext is a perfect cube:

m = integer_cube_root(c)

No factoring needed. Use Newton's method for the integer root; floats lose precision around 300 digits.

Lesson: this is why PKCS#1 v1.5 / OAEP padding exists. Unpadded RSA is malleable and, for small e, trivially invertible.

C7 — ECDSA nonce reuse · flag{nonce_reuse_71cbdf2491ed4108}

Two signatures, same key, same k. Since r is the x-coordinate of k·G, identical r means identical k.

k = (z1 - z2) / (s1 - s2)  mod n
d = (s1·k - z1) / r        mod n

Then verify: recompute d·G and check it equals the published public key. The solver does exactly that before printing the flag. Recovered d = 71cbdf24…66bc.

Lesson: this is the bug that broke the PS3 (Sony used a constant k) and has drained real Bitcoin wallets. The fix is a deterministic nonce (RFC 6979) or a CSPRNG you actually trust.
